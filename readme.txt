Description: A clean and responsive WordPress Block theme for bloggers and small businesses.

A full site editing theme focused on simple layouts, responsive design, and accessible defaults.

== Guide ==

=== Folder structure ===

- Assets. Images and CSS files.
- Parts. HTML template parts.
- Patterns. Block patterns.
- Templates. HTML block templates.

functions.php      - Used to enqueue styles and add theme support.
index.php          - "Silence is golden".
style.css          - Required to activate the theme.
theme.json         - Settings and default styles.
accessibility.txt  - Accessibility information and testing notes.
license.txt        - GPL v2.
readme.txt         - Information about the theme.
Screenshot.png     - Theme screenshot.

== Changelog ==

= 1.5.0 =
* Updated Tested up to value to WordPress 7.1.
* Added a functional skip-to-content link and main-content targets.
* Added screen-reader text and visible keyboard focus styles.
* Added accessibility.txt with accessibility information and reporting guidance.
* Updated the default color palette to a white background, dark text, and accessible blue accents.
* Changed the header from a blue background to a neutral white background.
* Reduced the front-page hero overlay and moved it to a neutral dark treatment.
* Simplified the fancy button styling and added reduced-motion handling.
* Corrected inconsistent version metadata.

= 1.0.0 =
* Initial release.
